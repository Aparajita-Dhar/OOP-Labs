# Object-Oriented Programming (OOP) Paradigms in Java

This repository contains academic implementations of Object-Oriented Programming principles. It serves as a comprehensive portfolio mapping out fundamental class architectures, inheritance graphs, clean interface decoupling, robust exception pipelines, and modern concurrent threading systems inside the Java ecosystem.

##  Repository Progress Index

### Phase 1: Core Encapsulation & Polymorphic Systems
* **`01_JavaBasics.java`**
  * Establishes basic syntax layouts, I/O handling, data primitive printing, and maps out Java Virtual Machine (JVM) compilation workflows.
* **`02_ClassAndObject.java`**
  * Features the instantiation of runtime Objects from static Class blueprints, memory initialization routines via constructor blocks, and attribute reference management.
* **`03_Polymorphism.java`**
  * Tracks poly-structural designs using both static compile-time polymorphism (Method Overloading) and active runtime dynamic method binding (Method Overriding).
    ### Phase 2: Hierarchical Extensions & Structural Contracts
* **`04_05_InheritanceEngine.java`**
  * Tracks object code reuse structures via single and multi-level inheritance graphs, using memory constructor chaining with the `super` reference handle.
* **`06_InterfaceArchitecture.java`**
  * Implements component decoupling patterns through formal Interface contracts, ensuring structural consistency across isolated runtime modules.
* **`06_PackageDemonstration.java`**
  * Outlines project file modularization and global namespace organization using explicit internal/external Java package dependency structures.
    ### Phase 3: Runtime Operations & Interface Layouts
* **`07_ExceptionPipeline.java`**
  * Implements defensive error processing mechanisms using structured `try-catch-finally` wrappers to maintain runtime stability during critical errors.
* **`07_ThreadConcurrency.java`**
  * Launches multi-tasking engines using Java `Thread` extensions, displaying parallel processing, thread sleep schedules, and concurrent execution pipelines.
* **`08_GuiArchitecture.java`**
  * Builds decoupled event-driven desktop interface displays using modern Java Swing containers (`JFrame`, `JButton`) and action event interceptors.
